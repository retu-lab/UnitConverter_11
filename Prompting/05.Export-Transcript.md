## Turn 1 — Command 작성·실행 방법 문의

**User:**
```
Report 폴더에 보고서 생성하고, Prompting 폴더에 Transcript도 Export 해줘.
01.XXX 형식으로 저장해야 해.

라는 프롬프트를 Command로 작성하고 실행하는 방법을 알려줘
```

**Assistant (요약 출력):**
- Cursor **Command** = 채팅 `/`로 불러오는 저장 프롬프트
- **방법 1 (권장):** `.cursor/commands/<이름>.md` — 파일명이 명령어, Git 공유 가능
- **방법 2:** Cursor Settings → Commands → Add Command
- 프로젝트 명명 규칙 정리:
  - `Report/NN.<주제>-Report.md`
  - `Prompting/NN.Export-Transcript.md`
- 현재 01~04 존재 → 다음은 05
- `export-session.md` 예시 본문 제공 (Report·Transcript 작성 지침, 번호 자동 증가, Turn 형식)
