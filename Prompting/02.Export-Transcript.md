## Turn 1 — 역할 분리 Mom Test 시뮬레이션 (3턴)

**User:**
```
역할 분리 Mom Test 시뮬레이션 (UnitConverter_11).
Role 1 — 인터뷰어: Mom Test 규칙 준수, 질문만
Role 2 — 페르소나: "프로그래밍 수업에서 부분 마방진 과제를 받은 학생"
  (가상이지만 plausible한 과거 사실만)
3턴 진행:
- Turn 1: 인터뷰어 질문 → 페르소나 답
- Turn 2: 추궁 → 답
- Turn 3: 추궁 → 답
마지막: 표면 문제 vs 진짜 문제 (가상 인터뷰임을 명시)
⚠️ 내 실제 경험과 섞지 말 것. 시뮬레이션 라벨 필수.
```

**Assistant (요약 출력):**

**Turn 1 — 질문 1**
- Q: 마지막으로 부분 마방jin 과제 제출 직전 막힌 때? 처음 뭘 하려다 → 처음부터 끝까지 순서
- A: 3/12 19:05~22:30. `fill_magic_square()` 완성 목표. 19:35 대각선 오류 → 19:50 손계산 → 20:15 첫 행 17 → 21:10 테스트2 while 반복 → 22:30 테스트1만 제출

**Turn 2 — 추궁**
- Q: 19:35~20:15 40분 동안 틀린 걸 어떻게 찾았어? 손계산·출력·PDF·카톡 중 어디에 시간?
- A: 오류 위치 ~15분(print 행만) / 손계산 ~20분(공책 4회, 15분 헛돌림) / PDF·카톡 ~5분. 한 칸 수정 시 연쇄 깨짐 판단 불가

**Turn 3 — 추궁**
- Q: 21:10 테스트2 막힘 → 23:59 전 포기한 정확한 순간? 그때까지 어디까지 / 포기 후 뭘 대신?
- A: 22:18 포기. while 3/7 번갈아 출력, break 조건 3회 변경. 룸메이트 10분만 확인. 제출 후 공책 12분 추가. 테스트1 10점 / 테스트2 0점

**인터뷰 종료 정리**
1. **표면 문제:** ~~자동 완성 프로그램~~ / ~~검증 디버거~~ / ~~while 검증 도구~~
2. **진짜 문제:** PDF 규칙·로직·손계산 기준 불확신 → 출력·공책·PDF 대조 반복 → 어느 칸/줄 깨졌는지 한 번에 못 짚음 → 일부 케이스만 제출
3. **증거 3줄:** 코드 vs 손계산 헷갈림 / 공책 4회·15분 헛돌림 / 22:18 테스트2 미완 제출

## Turn 2 — Mom Test 워크북 채점

**User:**
```
아래 Mom Test 결과를 채점해줘. 수정하지 마.
[워크북 전체]
체크:
- [ ] 미래 가정("~하면 좋겠다") 없음
- [ ] 과거 행동·시간·실수 구체성 있음
- [ ] 진짜 문제에 솔루션名(TDD/PyQt/Cursor) 없음
- [ ] 표면 문제와 진짜 문제가 분리됨
- [ ] 도면 yard / 견적 meter / 여유분 적용 순서 반영
점수 /10 + 고칠 질문 1개만 제안
```

**Assistant:**
- **점수: 9 / 10**
- 체크: 미래 가정 ✅ / 구체성 ✅ / 솔루션名 없음 ✅ / 표면·진짜 분리 ✅ / yard·meter·여유분 ❌ **N/A** (마방jin 페르소나)
- **감점 (−1):** 진짜 문제에 PDF·손계산·코드 출력 3-way 기준 명시 부족
- **고칠 질문:** Turn 3 → "21:10~22:18 while 3/7 번갈아 출력 시, 몇 시 몇 분에 break·합 검사 조건을 몇 번 바꿨고, 그때마다 출력이 어떻게 달라졌는지 순서대로"
