## 3. 산출물

### 3.1 boundary 모듈

| 파일 | 역할 |
|------|------|
| `src/boundary/conversion_service.py` | `to_meters()` · `convert_all()` — feet/yard 역환산 + entity 변환 |
| `src/boundary/result_display.py` | 변환 결과·E001~E003 오류·G1 검증 메시지 포맷 |
| `src/boundary/validation_gui.py` | PyQt6 `ValidationWindow` — 입력·변환·G1·U-IN 다이얼로그 |

### 3.2 실행·의존성

| 파일 | 역할 |
|------|------|
| `run_validation_gui.py` | 프로젝트 루트 GUI 진입점 |
| `requirements-gui.txt` | `PyQt6>=6.6` |

### 3.3 GUI 기능

| 기능 | 설명 |
|------|------|
| **입력** | `unit:value` (예: `meter:2.5`, `yard:12.5`) |
| **변환** | meter / feet / yard 세 줄 동시 출력 (소수 4자리) |
| **예시 버튼** | `meter:2.5`, `yard:12.5`, `feet:8.2021` 빠른 입력 |
| **G1 실행** | D-LOC-01/02 기대값 대비 PASS/FAIL |
| **U-IN 테스트** | `meter:abc`→E002, `unknown:1`→E003, 형식 오류→E001 다이얼로그 |
