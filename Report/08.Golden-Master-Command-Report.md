## 3. D-LOC-01 Golden Master 프롬프트 재설계

MagicSquare `int[6]`·에러 코드 규칙을 제거하고 Entity 변환 결과 **고정 텍스트 직렬화**로 대체.

### 3.1 Golden 포맷 (SSOT)

```
test_id: D-LOC-01
given_meters: {meters:.6f}
then_feet: {feet:.6f}
```

| 항목 | G1 값 |
|------|-------|
| `given_meters` | `2.500000` |
| `then_feet` | `8.202100` (= 2.5 × 3.28084) |

- 줄바꿈 LF, trailing newline 1개
- 수동 편집 우회 금지 — `UPDATE_GOLDEN=1`로만 갱신

### 3.2 D-SOL-01 → D-LOC-01 매핑

| 항목 | D-SOL-01 (revert됨) | D-LOC-01 (UnitConverter) |
|------|---------------------|--------------------------|
| 테스트 | `test_d_sol_01_step_a_success` | `test_d_loc_01_meter_to_feet` |
